# Моя музыка — v0.1

Плеер для музыки, которая лежит на телефоне. Интерфейс на Material Design 3
(цвета подстраиваются под обои на Android 12+, тёмная тема — по системе).

## Что уже умеет

- находит всю музыку на телефоне (через системную медиатеку);
- список треков с обложками и поиск по названию, исполнителю, альбому;
- играет в фоне, есть уведомление и управление с экрана блокировки;
- мини-плеер внизу и большой плеер (тап по мини-плееру): перемотка,
  пауза, следующий/предыдущий, перемешивание, повтор (выкл → весь список → один трек);
- пауза при отключении наушников.

## Как получить APK (без Android Studio)

1. Создай репозиторий на github.com и загрузи в него всё содержимое этой папки
   (включая скрытую папку `.github`).
   Если `.github` не загрузилась: Add file → Create new file → имя `.github/workflows/build.yml`,
   вставь туда содержимое файла build.yml.
2. Открой вкладку **Actions** → **Build APK** → **Run workflow**
   (сборка также запускается сама после каждой загрузки изменений).
3. Через 3–6 минут открой завершённый запуск, внизу в **Artifacts** скачай `MyMusic-debug-apk`.
4. Распакуй zip и установи `app-debug.apk` на телефон (разреши установку из неизвестных источников).

## Если собираешь в Android Studio

Открой папку как проект, дождись синхронизации Gradle и нажми Run.

## Структура

| Файл | Что делает |
|---|---|
| `PlaybackService.kt` | сам плеер (ExoPlayer) в фоновом сервисе |
| `PlayerViewModel.kt` | связывает экран и сервис, хранит состояние |
| `MusicRepository.kt` | читает треки из медиатеки |
| `ui/PlayerApp.kt` | весь интерфейс: список, мини-плеер, большой плеер |
| `ui/Theme.kt` | тема Material 3 |
