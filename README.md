# MyMusic

Музыкальный плеер для Android. Проигрывает музыку, которая уже лежит на телефоне — без облака и стриминга.

## Возможности

- находит всю музыку на устройстве через системную медиатеку;
- список треков с обложками и поиск по названию, исполнителю и альбому;
- фоновое воспроизведение с уведомлением и управлением с экрана блокировки;
- мини-плеер внизу и полноэкранный плеер: перемотка, пауза, следующий/предыдущий, перемешивание, повтор;
- пауза при отключении наушников;
- Material Design 3: цвета подстраиваются под обои на Android 12+, тёмная тема — по системе.

## Технологии

- Kotlin + Jetpack Compose;
- ExoPlayer (Media3) для воспроизведения;
- Coil для загрузки обложек;
- MVVM (ViewModel + Repository).

## Структура проекта

| Файл | Что делает |
|---|---|
| `PlaybackService.kt` | сам плеер (ExoPlayer) в фоновом сервисе |
| `PlayerViewModel.kt` | связывает экран и сервис, хранит состояние |
| `MusicRepository.kt` | читает треки из медиатеки |
| `ui/PlayerApp.kt` | весь интерфейс: список, мини-плеер, большой плеер |
| `ui/Theme.kt` | тема Material 3 |

## Планы

плейлисты, избранное, очередь воспроизведения, таймер сна, эквалайзер, сортировка по дате и исполнителю, экран альбомов и исполнителей.
