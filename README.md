# Моя музыка 0.2 (Rust + Slint)

Плеер для музыки, которая лежит на телефоне. Написан на Rust, интерфейс на Slint
в стиле Material (светлая и тёмная тема, можно выбрать в настройках).

## Что умеет

- Находит всю музыку на телефоне (mp3, flac, ogg, m4a, aac, wav), читает теги и обложки.
- Список с поиском и **ползунком быстрой прокрутки**: возьмись за полоску справа и тяни
  вверх/вниз, рядом покажется буква, до которой долистал.
- Окно плеера открывается само при запуске песни: сверху слева обложка, справа название,
  под ним автор; снизу полоса перемотки и кнопки (перемешать, назад, пауза, вперёд, повтор).
- **Скрыть трек**: кнопка «⋮» в строке → «Скрыть из плеера». Файл остаётся на телефоне,
  вернуть можно в настройках («Скрытые треки» → «Показать все»).
- **Удалить трек**: «⋮» → «Удалить с телефона…» → подтверждение. Файл удаляется навсегда.
  При первом удалении приложение откроет экран системных настроек: включи там
  «Доступ ко всем файлам», вернись в приложение и повтори удаление.
- Записи мессенджеров и диктофона скрыты (можно выключить в настройках), рингтоны и
  уведомления скрыты всегда.
- Настройки: тема, фильтры записей, минимальная длина трека, сортировка, автооткрытие плеера.

## Как получить APK (без Android Studio)

1. Создай репозиторий на github.com и загрузи в него всё содержимое этой папки
   (включая скрытую папку `.github`).
2. Открой вкладку **Actions** → **Build APK** → **Run workflow**.
3. Первая сборка идёт долго (15–25 минут: собирается Rust и все библиотеки), потом быстрее.
4. Внизу страницы завершённого запуска в **Artifacts** скачай `MyMusic-rust-apk`,
   распакуй zip и установи `MyMusic.apk` на телефон.

Если сборка упала, открой красный шаг в Actions и пришли мне текст ошибки, я поправлю.

## Что я не мог проверить

Проект написан без возможности собрать его (в моей среде нет сети и Android SDK),
поэтому на первой сборке возможны мелкие ошибки компиляции. Особенно вероятны места,
где я опирался на документацию, а не на запуск:

- имена типов и функций в `rodio` 0.22 (`src/engine.rs`);
- теги и обложки в `lofty` 0.22 (`src/library.rs`);
- синтаксис `ui/app.slint` (ползунок прокрутки, меню, настройки);
- запрос разрешений и удаление через JNI (`src/platform.rs`);
- сборка под Android: нужна свежая версия NDK, на старых приложение может падать при запуске.

Проверено компилятором только `src/settings.rs` (настройки и список скрытых треков).

## Чем эта версия хуже Kotlin-версии

- Нет уведомления с кнопками и управления с экрана блокировки.
- Фоновое воспроизведение не гарантировано: если система закроет свернутое приложение,
  музыка остановится. Лечится небольшим фоновым сервисом, это следующий шаг.
- Нет автопаузы при отключении наушников.
- В списке нет обложек (они показываются в мини-плеере и в окне плеера).

## Структура

| Файл | Что делает |
|---|---|
| `ui/app.slint` | весь интерфейс: список, ползунок, мини-плеер, окно плеера, меню, настройки |
| `src/lib.rs` | связывает интерфейс с логикой, состояние приложения |
| `src/engine.rs` | проигрыватель: очередь, перемешивание, повтор, перемотка |
| `src/library.rs` | поиск файлов, теги, фильтры, обложки |
| `src/settings.rs` | настройки и список скрытых треков |
| `src/platform.rs` | Android: разрешения, доступ ко всем файлам, оповещение медиатеки |
